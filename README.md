Core Features：

1.User Login & Authentication
2.RAG Knowledge Base Module: Upload technical documents and tutorials; perform private knowledge‑base retrieval
3.MCP Service Management Module: Enable / disable MCP tools: MySQL query tool, local file reading tool, document retrieval tool
4.AI Chat Module: The LLM automatically determines whether to invoke MCP tools; supports database query, local document reading and knowledge‑base retrieval
5.Chat Session Management, visualized tool‑call logs (view tool input parameters and return results)
6.Vue Front‑end: Chat interface, MCP tool switch panel, knowledge‑base management interface
7.Basic Statistics: Number of conversations, number of tool invocations
